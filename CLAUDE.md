# OpenAI OAuth

## What This Is
Free AI via your ChatGPT account: OAuth bridge + dev proxy, TypeScript SDK packages, browser extension, shared lib. Monorepo (bun).

## Non-Negotiables
- Never commit or log ChatGPT session credentials from `~/.codex`.
- Read this project's own README first — it is a vendored upstream project.

## Commands
- Proxy: `npx openai-oauth@latest`
- Deps: `bun install` (see README for per-package commands)
